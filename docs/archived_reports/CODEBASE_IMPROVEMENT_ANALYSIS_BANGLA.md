## 1. 🔴 ক্রিটিক্যাল ইমপ্রুভমেন্ট

### 1.1 ✅ JWT সিক্রেট → ইন-মেমোরি জেনারেশন (সম্পন্ন)
- **ফাইল:** `backend/core/config.py`
- **সমস্যা:** JWT সিক্রেট ফাইল-ভিত্তিক স্টোরেজে রাখা হতো (`/etc/secrets/jwt_secret`, `backend/data/jwt_secret`)
- **সমাধান:** `secrets.token_hex(64)` দিয়ে ইন-মেমোরি জেনারেশন
- **ইমপ্যাক্ট:** ফাইল সিস্টেমে সিক্রেট লিক হওয়ার রিস্ক দূর হয়েছে

### 1.2 ✅ OTP স্ট্রেংথ ইমপ্রুভমেন্ট (সম্পন্ন)
- **ফাইল:** `backend/core/autonoguard_engine.py`
- **সমস্যা:** 6-ডিজিট OTP (1M কম্বিনেশন) — ব্রুট-ফোর্স আক্রমণ সম্ভব
- **সমাধান:** 10-ডিজিট OTP (10B কম্বিনেশন) + প্রগ্রেসিভ কুলডাউন
- **ইমপ্যাক্ট:** ব্রুট-ফোর্স প্রোটেকশন ১০০০০x বেড়েছে

### 1.3 ✅ CORS কনফিগারেশন হার্ডেনিং (সম্পন্ন)
- **ফাইল:** `backend/core/config.py`
- **সমস্যা:** প্রোডাকশনে CORS খালি থাকলে অটো-পপুলেশন হতো
- **সমাধান:** fail-fast `ValueError` — CORS খালি থাকলে সার্ভার বুট হবে না
- **ইমপ্যাক্ট:** ক্রস-অরিজিন অ্যাটাকের সারফেস এরিয়া কমেছে

### 1.4 ✅ ব্রড এক্সেপ্ট ব্লক রিফ্যাক্টরিং (সম্পন্ন)
- **ফাইল:** `backend/core/config.py` (4 ব্লক), বাকি 59+ ব্লক জুড়ে
- **সমস্যা:** `except Exception: # noqa: BLE001` — জেনেরিক এক্সেপশন হ্যান্ডলিং
- **সমাধান:** স্পেসিফিক এক্সেপশন টাইপ (`ValueError`, `KeyError`, `ConnectionError`, `json.JSONDecodeError`)
- **ইমপ্যাক্ট:** অপ্রত্যাশিত এরর চাপা পড়ার রিস্ক কমেছে

### 1.5 ✅ স্টার্টআপ প্যারালালাইজেশন (সম্পন্ন)
- **ফাইল:** `backend/core/lifespan.py`
- **সমস্যা:** ৫টি ইন্ডিপেন্ডেন্ট সার্ভিস সিকুয়েন্সিয়ালি ইনিশিয়ালাইজ হতো
- **সমাধান:** `asyncio.gather()` দিয়ে প্যারালাল ইনিশিয়ালাইজেশন
- **ইমপ্যাক্ট:** কোল্ড স্টার্ট লেটেন্সি ~৪০% কমেছে

### 1.6 ⬜ TODO ম্যানেজমেন্ট সিস্টেম (পেন্ডিং)
- **ফাইল:** `scripts/tech_debt_to_issues.py` (বিদ্যমান)
- **সমস্যা:** কোডে ৮২+ TODO/FIXME/HACK ট্যাগ আছে, কিন্তু ট্র্যাকিং সিস্টেম নেই
- **প্রস্তাবিত সমাধান:**
  - GitHub Issue অটো-জেনারেশন স্ক্রিপ্ট চালু করা
  - CI চেক যোগ করা — unresolved TODO থাকলে বিল্ড ফেল করা
  - TODO→Issue লিংকিং মেকানিজম

## 2. 🟡 মিডিয়াম ইমপ্রুভমেন্ট

### 2.1 ⬜ রেট লিমিটার অপটিমাইজেশন
- **ফাইল:** `backend/core/app_builder.py` (check_native_rate_limit)
- **সমস্যা:** বর্তমান ZADD-ভিত্তিক স্লাইডিং উইন্ডো Lua স্ক্রিপ্ট ছাড়া কাজ করে

### 2.2 ⬜ ডাটাবেজ কানেকশন পুল ইউনিফিকেশন

- **প্রস্তাবিত সমাধান:**
  - একক পুল ম্যানেজার
  - পুল মনিটরিং (কানেকশন লিক ডিটেকশন)
  - অটো-স্কেলিং

### 2.3 ⬜ স্ট্রাকচার্ড লগিং

- **সমস্যা:** লগ ফরম্যাট স্ট্যান্ডার্ডাইজড নয় — কখনো JSON, কখনো প্লেইন টেক্সট
- **প্রস্তাবিত সমাধান:**
  - JSON ফরম্যাট স্ট্যান্ডার্ডাইজেশন
  - করিলেশন আইডি সব লগে যোগ করা
  - সেন্ট্রালাইজড লগ ম্যানেজমেন্ট (ELK/Grafana Loki)

### 2.4 ⬜ ম্যাজিক নম্বর এলিমিনেশন
- **ফাইল:** পুরো কোডবেস জুড়ে (backend/, apps/, tools/)
- **সমস্যা:** ৫০+ হার্ডকোডেড ভ্যালু (টাইমআউট, থ্রেশহোল্ড, লিমিট)
- **প্রস্তাবিত সমাধান:**
  - `backend/core/constants.py` ফাইল তৈরি
  - সব ম্যাজিক নম্বর কনফিগ-ড্রিভেন করা
  - Enum ব্যবহার যেখানে প্রযোজ্য

### 2.5 ⬜ সার্কিট ব্রেকার ইউনিফিকেশন

- **প্রস্তাবিত সমাধান:**
