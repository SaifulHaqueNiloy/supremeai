# সুপ্রিমএআই ভিএসকোড এক্সটেনশন পাওয়ার উপায় - বাংলা

## পরিচিতি

এই নথিতে সুপ্রিমএআই ভিএসকোড এক্সটেনশন পাওয়ার দুটি পদ্ধতি বর্ণনা করা হয়েছে:
1. লোকালি বিল্ড করে ইনস্টল করা
2. গিটহাব থেকে ডাউনলোড করে ইনস্টল করা

## পদ্ধতি 1: গিটহাব থেকে ডাউনলোড করা (সহজ পদ্ধতি)

### সুবিধা:
- কোনো ডেভেলপমেন্ট এনভায়রনমেন্ট প্রয়োজন নেই
- সরাসরি ইনস্টল করা যায়
- অফিশিয়াল রিলিজ ভার্সন

### ধাপসমূহ:

1. **গিটহাব রিপোজিটরিতে যান**
   - URL: https://github.com/your-org/supremeai
   - রিপোজিটরি খুঁজুন: `supremeai/supremeai`

2. **রিলিজ পেজে যান**
   - রিপোজিটরির হোমপেজে "Releases" ট্যাবে ক্লিক করুন
   - সবচেয়ে সাম্প্রতিক রিলিজ নির্বাচন করুন (উদাহরণ: v6.0.0)

3. **Vsix ফাইল ডাউনলোড করুন**
   - রিলিজ পেজে "Assets" সেকশন খুঁজুন
   - `supremeai-vscode-X.X.X.vsix` ফাইলটি ডাউনলোড করুন

4. **এক্সটেনশন ইনস্টল করুন**
   - ডাউনলোড করা vsix ফাইলে ডবল-ক্লিক করুন
   - অথবা ভিএসকোডে গিয়ে: `Ctrl+Shift+P` → "Extensions: Install from VSIX" → ফাইল সিলেক্ট করুন

## পদ্ধতি 2: লোকালি বিল্ড করা

### সুবিধা:
- নতুনতম ডেভেলপমেন্ট ভার্সন পাওয়া যায়
- কাস্টম মডিফিকেশন করা যায়
- টেস্টিং এর জন্য উপযোগী

### প্রয়োজনীয় সফটওয়্যার:
- Node.js (>= 16.x)
- pnpm (>= 8.x)
- Git
- VSCode

### ধাপসমূহ:

1. **রিপোজিটরি ক্লোন করুন**
   ```bash
   git clone https://github.com/your-org/supremeai.git
   cd supremeai
   ```

2. **প্রয়োজনীয় ডিপেন্ডেন্সি ইনস্টল করুন**
   ```bash
   cd tools/vscode-extension
   pnpm install
   ```

3. **এক্সটেনশন বিল্ড করুন**
   ```bash
   pnpm package-ext
   ```

   অথবা সম্পূর্ণ প্রক্রিয়া:
   ```bash
   pnpm compile
   pnpm package-ext
   ```

4. **Vsix ফাইল পাবেন**
   - ফাইলটি পাবেন: `supremeai-vscode-X.X.X.vsix`
   - এখন এটি ইনস্টল করুন পদ্ধতি 1 এর মতো

## রিপোজিটরি কাঠামো

গিটহাব রিপোজিটরিতে এক্সটেনশন ফাইলগুলি পাবেন:
```
supremeai/
├── tools/
│   └── vscode-extension/
│       ├── package.json          # এক্সটেনশন ম্যানিফেস্ট
│       ├── src/                  # সোর্স কোড
│       ├── media/                # অ্যাসেট ফাইল
│       └── README.md             # ডকুমেন্টেশন
```

## রিলিজ প্রসেস

প্রতিবার নতুন ভার্সন রিলিজের সময়:
1. GitHub Actions অটোমেটিক বিল্ড চালায়
2. এক্সটেনশন প্যাকেজ করা হয়
3. VSIX ফাইল রিলিজ এসেট হিসেবে আপলোড হয়
4. Marketplace-এ পাবলিশ করা হয় (যদি অনুমদন দেওয়া হয়)

## ট্রাবলশুটিং

### গিটহাব থেকে ডাউনলোড সংক্রান্ত সমস্যা:
- রিপোজিটরি প্রাইভেট হলে অ্যাক্সেস থাকতে হবে
- সঠিক রিলিজ ভার্সন নির্বাচন করুন

### লোকালি বিল্ড সংক্রান্ত সমস্যা:
- ডিপেন্ডেন্সি ইনস্টল নিশ্চিত করুন
- সঠিক Node.js এবং pnpm ভার্সন ব্যবহার করুন
- সমস্যা হলে `pnpm clean` এবং পুনরায় ইনস্টল করুন

## নিরাপত্তা বিবেচনা

- শুধুমাত্র অফিশিয়াল রিপোজিটরি থেকে এক্সটেনশন ডাউনলোড করুন
- অজ্ঞাত উৎস থেকে vsix ফাইল ইনস্টল করবেন না
- লোকালি বিল্ড করা এক্সটেনশনগুলি শুধুমাত্র টেস্টিং এর জন্য ব্যবহার করুন

## উপসংহার

গিটহাব থেকে ডাউনলোড করা হলো সহজ এবং দ্রুত উপায়, যেখানে লোকালি বিল্ড করা হলো কাস্টমাইজেশন এবং ডেভেলপমেন্ট এর জন্য উপযোগী। আপনার প্রয়োজন অনুযায়ী উপযুক্ত পদ্ধতি বেছে নিন।
