# SupremeAI Plans Archive

**Status:** active  
**Purpose:** Preserves superseded, legacy, and consolidated plan documents per AGENTS.md living asset protection rules.

## Directory Structure

- `redirect_stubs/` — Redirect stubs pointing to canonical active plans
- `redirect_stubs/summary/` — Summary redirect stubs
- `features/legacy_plan_series_2026_05/` — Legacy May 2026 Java/Spring Boot prototype plans (Plan_12–15, Plan_17–21)
- `features/free_tier_federation_master_plan_v3_superseded.md` — Superseded free-tier federation plan v3
- `summary/duplicate_originals/` — Exact SHA1 duplicate originals from docs/plans/summary/

## Archive Policy

Archived documents are never deleted. They remain accessible for historical reference and lineage tracing. When a plan is superseded, its redirect stub is moved here and updated to point to the new canonical version.
