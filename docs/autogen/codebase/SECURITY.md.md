# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within SupremeAI 2.0, please report it immediately to the security team. Do not open public Github issues for security flaws.

Please send details of the vulnerability to: `security@supremeai.dev`

We will review your submission and respond as quickly as possible.
