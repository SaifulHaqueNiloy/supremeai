# SupremeAI 2.0 MCP Servers

এই ডিরেক্টরিতে SupremeAI 2.0-এর জন্য কাস্টম MCP সার্ভারগুলো রয়েছে।

## MCP সার্ভারগুলো

### workspace_mcp.py
ডাইনামিক ওয়ার্কস্পেস আইসোলেশন সার্ভার। একাধিক প্রজেক্টের জন্য স্কোপযুক্ত ফাইল পাথ ম্যানেজমেন্ট।

টুলস:
- `workspace_set_context`: বর্তমান ওয়ার্কস্পেস কনটেক্সট সেট করে
- `workspace_get_scoped_path`: স্কোপযুক্ত ফাইল পাথ রিট্রাইস করে
- `workspace_list_projects`: উপলব্ধ প্রকল্পগুলোর তালিকা দেখায়

### supabase_mcp.py
Supabase/Postgres ডাটাবেস ইন্টিগ্রেশন সার্ভার। সরাসরি ডাটাবেস অপারেশন।

টুলস:
- `supabase_execute_sql`: SQL কুয়েরি এক্সিকিউট
- `supabase_create_table`: টেবিল তৈরি
- `supabase_run_migration`: ডেটাবেস মাইগ্রেশন
- `supabase_list_tables`: টেবিল তালিকা

### cloud_deploy_mcp.py
রেন্ডার, রেলওয়ে, ওয়াক্লু-ক্লাউড ডিপ্লয়মেন্ট সার্ভার।

টুলস:
- `cloud_deploy_service`: ক্লাউডে সার্ভিস ডিপ্লয়
- `cloud_get_deployment_logs`: ডিপ্লয়মেন্ট লগ রিট্রিভ
- `cloud_list_services`: সক্রিয় সার্ভিস তালিকা

### github_cicd_mcp.py
GitHub CI/CD ইন্টিগ্রেশন সার্ভার।

টুলস:
- `github_create_pull_request`: PR তৈরি
- `github_run_auto_fix`: CI অটো-ফিক্স চালান
- `github_list_issues`: ইস্যু তালিকা
- `github_get_ci_status`: CI স্ট্যাটাস চেক
