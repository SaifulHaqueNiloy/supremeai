# Common Technical Errors in Large-Scale AI & Web Projects

লার্জ-স্কেল এন্টারপ্রাইজ প্রজেক্ট এবং এআই অর্কেস্ট্রেশন সিস্টেমে (যেমন SupremeAI 2.0) সচরাচর যেসব জটিল টেকনিক্যাল এরর এবং বাগ দেখা যায়, সেগুলোর ক্যাটাগরি অনুযায়ী টেকনিক্যাল নাম, মূল কারণ এবং সমাধানের গাইডলাইন নিচে দেওয়া হলো।

---

## 1. Security & Webview Errors (সিকিউরিটি ও ইউআই ফিল্টার এরর)

| Technical Error Term | বাংলা নাম / পরিচিতি | বিবরণ ও মূল কারণ |
|---|---|---|
| **Content Security Policy (CSP) Violation** | কন্টেন্ট সিকিউরিটি পলিসি ভায়োলেশন | ব্রাউজার বা VS Code Webview-তে ডুপ্লিকেট বা কঠোর CSP ট্যাগের কারণে ইনলাইন জাভাস্ক্রিপ্ট বা বাটন ইভেন্ট লিসেনার ব্লক হওয়া। |
| **Cross-Origin Resource Sharing (CORS) Blocked** | সিওআরএস ব্লকড | ফ্রন্টএন্ড থেকে ব্যাকএন্ড এপিআই কলে অনুরোধ পাঠানোর সময় ব্যাকএন্ডের `CORS_ORIGINS` হেডার সঠিক ডোমেন অ্যালাউ না করলে নেটওয়ার্ক ব্লক হওয়া। |
| **Cross-Site Scripting (XSS)** | ক্রস-সাইট স্ক্রিপ্টিং | অনিরাপদ ইনপুট বা রেণ্ডারিংয়ের মাধ্যমে ক্ষতিকর স্ক্রিপ্ট রান হওয়া। |
| **Command / Shell Injection** | শ্যাল ইনজেকশন | সিস্টেম সেল কমান্ড স্পন করার সময় ইনপুট প্রপারলি স্যানিটাইজ না করা। |

## 2. Infrastructure & Configuration Errors (ইনফ্রাস্ট্রাকচার ও কনফিগ এরর)

| Technical Error Term | বাংলা নাম / পরিচিতি | বিবরণ ও মূল কারণ |
|---|---|---|
| **Configuration Drift** | কনফিগারেশন ড্রিপ্ট | প্রোডাকশন ক্লাউড সার্ভিস এবং কোডবেসের ইনফ্রাস্ট্রাকচার-অ্যাজ-কোড (`render.yaml` / `terraform`) ফাইলের সাথে সেটিংসের অমিল হওয়া। |
| **Secret Invalidation / Rotation Drift** | সিক্রেট সিঙ্ক ফেলিউর | কোনো সার্ভিস বা প্ল্যাটফর্মে API Key পরিবর্তন হলেও বাকি প্ল্যাটফর্মগুলোতে সিঙ্ক না থাকা। |
| **Hardcoded Endpoint Binding** | হার্ডকোডেড এন্ডপয়েন্ট বালাই | ডেভেলপমেন্ট বা লোকাল URL কোডের ভেতর রয়ে গিয়ে প্রোডাকশনে ভুল ব্যাকএন্ডে কল যাওয়া। |
| **Health Check Probe Timeout** | হেলথ চেক টাইমআউট | ক্লাউড কন্টেইনার চালুর সময় হেলথ চেক এন্ডপয়েন্ট (`/health`) দ্রুত রেসপন্স না করায় কন্টেইনার কিল হওয়া। |

## 3. Distributed State & Network Errors (নেটওয়ার্ক ও স্টেট এরর)

| Technical Error Term | বাংলা নাম / পরিচিতি | বিবরণ ও মূল কারণ |
|---|---|---|
| **Session Cache Poisoning (Stale Cache)** | ক্যাশ পয়েন্টজনিং / স্টেল ক্যাশ | ব্রাউজারের `sessionStorage` বা `localStorage`-এ পুরনো/মৃত ব্যাকএন্ড URL জমা থাকায় সার্ভিস ফেইল করা। |
| **Cascading Failure** | ক্যাসকেডিং ফেলিউর | মূল একটি ব্যাকএন্ড সার্ভিস ডাউন হওয়ার কারণে সাথে যুক্ত অন্য সমস্ত মাইক্রোসার্ভিস বা এজেন্ট পর পর ক্র্যাশ করা। |
| **Rate Limit Exceeded (HTTP 429)** | রেট লিমিট এক্সিডেড | ওপেন-সোর্স বা ফ্রি-টিয়ার AI Provider-এর ডেইলি টোকেন লিমিট বা রিকুয়েস্ট লিমিট শেষ হয়ে যাওয়া। |
| **Unhandled Edge-Case Race Condition** | রেস কন্ডিশন | একাধিক অ্যাসিঙ্ক্রোনাস রিকুয়েস্ট বা এজেন্ট একই ডাটা স্টেট একসাথে আপডেট করতে গিয়ে ডাটা করাপ্ট করা। |

## 4. Code Hygiene & Maintenance Errors (কোড হাইজিন ও আর্কিটেকচার এরর)

| Technical Error Term | বাংলা নাম / পরিচিতি | বিবরণ ও মূল কারণ |
|---|---|---|
| **False-Positive Claim (Regressive Bug)** | রিগ্রেসিভ বাগ | কোনো বাগ ফিক্স হয়েছে বলে দাবি করা হলেও কোডবেসের সব ফাইল বা মডিউলে সেই ফিক্স প্রয়োগ না হওয়া। |
| **Silent Failure / Exception Swallowing** | সাইলেন্ট ফেলিউর | `try/except` ব্লকে ভুলভাবে এরর হ্যান্ডেল করে খালি রেসপন্স দেওয়া বা এরর লগ না করা। |
| **Unused / Dead Code Dependency** | ডেড কোড ডিপেন্ডেন্সি | অব্যবহৃত মডিউল বা ইম্পোর্ট কোডে থেকে যাওয়া যা ভবিষ্যতে ভুলবশত ইম্পোর্ট হলে সিস্টেম ভেঙে দেয়। |
| **Unhandled Promise Rejection** | আনহ্যান্ডেল্ড প্রমিস রিজেকশন | অ্যাসিঙ্ক/অ্যাওয়েট লজিক কাজ করার সময় ভুল বা এরর রিজেকশন হ্যান্ডেল না করা। |

## 5. Performance & Resource Errors (পারফরম্যান্স ও রিসোর্স এরর)

| Technical Error Term | বাংলা নাম / পরিচিতি | বিবরণ ও মূল কারণ |
|---|---|---|
| **Cross-Service Configuration Contamination** | কনফিগারেট কনটামিনেশন | একাধিক সার্ভিস বা ফ্রন্টএন্ড পোর্টে ভিন্ন ব্যাকএন্ড থাকার পরও ভুলে জেনেরিক বা একই কনফিগারেশন ইউআরএল ব্যবহার হওয়া। |
| **Secret Invalidation & Key Drift** | সিক্রেট সিঙ্ক বিচ্যুতি | কোনো সার্ভিস বা প্ল্যাটফর্মে API Key পরিবর্তন হলেও বাকি প্ল্যাটফর্মগুলোতে সিঙ্ক না থাকা। |
| **Session Cache Poisoning (Stale Cache)** | ক্যাশ পয়েন্টজনিং / স্টেল ক্যাশ | ব্রাউজারের `sessionStorage` বা `localStorage`-এ পুরনো/মৃত ব্যাকএন্ড URL জমা থাকায় সার্ভিস ফেইল করা। |
| **Memory Leak / Resource Exhaustion** | মেমোরি লিক | অনাকাঙ্ক্ষিত টাইমার, ইভেন্ট লিসেনার বা গ্লোবাল ডাটা রিলিজ না করায় র‍্যাম ফুল হয়ে যাওয়া। |
| **Event Loop Blocking** | ইভেন্ট লুপ ব্লকিং | অ্যাসিঙ্ক্রোনাস সিস্টেমে ভারী সিঙ্ক্রোনাস প্রসেস চালানোর ফলে মেইন থ্রেড ফ্রিজ হয়ে যাওয়া। |
| **Unmocked Network Dependency Timeout** | আনমকড নেটওয়ার্ক টাইমআউট | অটোমেটেড টেস্টিং চালুর সময় লাইভ ক্লাউড সার্ভিস মক না করার ফলে টেস্ট হ্যাং করা বা ব্যর্থ হওয়া। |
