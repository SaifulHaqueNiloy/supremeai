# Walkthrough: Smart CI Failure Auto-Report System

## কী পরিবর্তন করা হয়েছে

### [supreme-ci.yml](file:///c:/Users/n/supremeai/supremeai_2.0/.github/workflows/supreme-ci.yml) (Line 872-1068)

পুরানো `notify` job (32 lines) → নতুন `ci-report` job (187 lines)

#### আগে (notify job):
- শুধু `echo` দিয়ে ASCII box-এ result print করতো
- Discord-এ generic "CI failed" / "CI passed" message পাঠাতো
- **কোন job fail হয়েছে তা জানার উপায় ছিল না** — ম্যানুয়ালি খুঁজতে হতো

#### এখন (ci-report job) — 3 Layer:

| Layer | কী করে | কোথায় দেখবেন |
|-------|--------|--------------|
| **📝 GitHub Job Summary** | Color-coded table: ❌ Failed / ✅ Passed / ⏭️ Skipped | Run page → Summary tab |
| **💬 Discord Rich Embed** | Failed job names সহ colored embed | Discord channel |
| **📎 Artifact** | `failure-report.md` download | Run page → Artifacts |

#### Key Technical Details:

1. **Array-based job collection** — `declare -a` ব্যবহার করে ১৩টি job-এর name ও result array-তে রাখা হয়, তারপর loop দিয়ে categorize করা হয়
2. **`$GITHUB_STEP_SUMMARY`** — GitHub-এর built-in feature যেটা Run page-এর Summary tab-এ markdown render করে
3. **`$GITHUB_OUTPUT`** — Report step থেকে Discord step-এ data pass করার জন্য
4. **Conditional artifact upload** — শুধু failure থাকলেই artifact upload হয়
