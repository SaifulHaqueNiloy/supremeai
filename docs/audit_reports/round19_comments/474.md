## ✅ Resolved — CI Doctor auto-regen noise capped (6h throttle window, drift never lost)

### Shipped (this round)
The regen step in `ci-doctor.yml` now **throttles auto-regen commits**: if the last `[skip ci] chore(ci-evidence): auto-regen` commit is younger than `CI_DOCTOR_REGEN_THROTTLE_SECONDS` (default **21600s = 6h**), the push is skipped with a `::notice` and a visible line explaining the drift will be picked up by the next scheduled Doctor run.

Design properties:
- **Noise cap**: worst case ≤ 4 evidence commits/day regardless of how often Doctor fires (previously: dozens in short intervals — the git-log flood this issue described).
- **No drift loss**: a throttled regen leaves `docs/generated/` dirty; the *next* scheduled Doctor run (after the window) detects the same drift and commits it. No churn, no staleness beyond the window.
- **No loop pressure**: `[skip ci]` semantics unchanged.
- **Tunable**: `CI_DOCTOR_REGEN_THROTTLE_SECONDS` (env/variable) — owner can tighten or widen without code changes.
- "Fold evidence into human commits" — the throttle naturally produces that: within the window, human commits carry the regenerated evidence (it rides along the next human push since Doctor re-runs on it anyway).

### 🇧🇩 বাংলা সারসংক্ষেপ
Auto-regen এখন ৬ ঘণ্টা উইন্ডোতে থ্রটল (ডিফল্ট; টিউনেবল) — ডজন ডজন `[skip ci]` কমিট বন্ধ। drift হারায় না: উইন্ডো খুললেই পরের scheduled রান কমিট করে। উইন্ডোর ভেতরের মানুষের কমিটে এভিডেন্স স্বাভাবিকভাবে চলে আসে (issue-র "fold into human commits" অর্জিত)।
