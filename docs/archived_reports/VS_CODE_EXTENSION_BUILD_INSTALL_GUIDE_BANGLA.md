# সুপ্রিমএআই ভিএসকোড এক্সটেনশন বিল্ড ও ইনস্টল গাইড - বাংলা

## পরিচিতি

এই নথিতে সুপ্রিমএআই ভিএসকোড এক্সটেনশন বিল্ড করার এবং লোকাল ডিভাইসে ইনস্টল করার পদ্ধতি বর্ণনা করা হয়েছে।

## প্রয়োজনীয় সফটওয়্যার

1. **Node.js** (>= 16.x)
2. **pnpm** (>= 8.x)
3. **VSCode** ইনস্টল করা থাকতে হবে
4. **VSCE** (Visual Studio Code Extension Manager) - ইনস্টল করতে হবে:
   ```bash
   npm install -g @vscode/vsce
   ```
5. অথবা **ESBuild** (প্রকল্পে ইতিমধ্যে ইনস্টল রয়েছে)

## বিল্ড প্রক্রিয়া

### 1. প্রকল্প ডিরেক্টরি চেঞ্জ করুন

```bash
cd c:\Users\n\supremeai\supremeai_2.0\tools\vscode-extension
```

### 2. ডিপেন্ডেন্সি ইনস্টল করুন

```bash
pnpm install
```

### 3. এক্সটেনশন কম্পাইল করুন

```bash
pnpm compile
```

অথবা সরাসরি টাইপস্ক্রিপ্ট কম্পাইল করুন:

```bash
npx tsc -p ./
```

### 4. এক্সটেনশন বান্ডিল করুন (Vsix ফাইল তৈরি)

```bash
pnpm package-ext
```

অথবা যদি vsce ইনস্টল করা থাকে:

```bash
vsce package
```

## প্রকল্পের স্ক্রিপ্ট

প্রকল্পে নিম্নলিখিত স্ক্রিপ্টগুলি রয়েছে:

- `pnpm compile` - টাইপস্ক্রিপ্ট কম্পাইল করে
- `pnpm package-ext` - ESBuild ব্যবহার করে এক্সটেনশন বান্ডিল করে
- `pnpm vscode:prepublish` - প্রকাশনার আগে এক্সটেনশন প্যাকেজ করে

## লোকাল এক্সটেনশন ইনস্টল করা

### পদ্ধতি 1: VSCode এর মাধ্যমে

1. VSCode ওপেন করুন
2. `Ctrl+Shift+P` চাপুন (কমান্ড প্যালেট ওপেন হবে)
3. "Extensions: Install from VSIX" টাইপ করুন
4. এন্টার চাপুন
5. বিল্ড করা `.vsix` ফাইল সিলেক্ট করুন

### পদ্ধতি 2: টার্মিনাল এর মাধ্যমে

```bash
code --install-extension supremeai-vscode-6.0.0.vsix
```

## বিল্ড প্রক্রিয়া যাচাই

1. সবগুলো টাইপস্ক্রিপ্ট ফাইল কম্পাইল হয়েছে কিনা দেখুন ([out](file:///c%3A/Users/n/supremeai/supremeai_2.0/backend/out) ডিরেক্টরিতে)
2. এক্সটেনশন ম্যানিফেস্ট ([package.json](file:///c%3A/Users/n/supremeai/supremeai_2.0/tools/vscode-extension/package.json)) সঠিক কিনা যাচাই করুন
3. সবগুলো ডিপেন্ডেন্সি ইনস্টল হয়েছে কিনা দেখুন

## সমস্যা সমাধান

### কম্পাইলেশন সমস্যা
- টাইপস্ক্রিপ্ট ভার্সন চেক করুন
- `tsconfig.json` সেটিং সঠিক কিনা দেখুন
- সবগুলো টাইপ ডিফিনিশন ইনস্টল করা আছে কিনা দেখুন

### প্যাকেজিং সমস্যা
- `vsce` ইনস্টল করা আছে কিনা দেখুন
- `package.json` এর সব আবশ্যিক ফিল্ড আছে কিনা চেক করুন
- এক্সটেনশন আকার ১০০MB এর বেশি হলে সমস্যা হতে পারে

## নিরাপত্তা বিবেচনা

- এক্সটেনশন শুধুমাত্র ট্রাস্টেড সোর্স থেকে ইনস্টল করুন
- লোকালি বিল্ড করা এক্সটেনশনগুলি টেস্টিং এর জন্য ব্যবহার করুন
- প্রোডাকশনে শুধুমাত্র অফিশিয়াল ভার্সন ব্যবহার করুন

## উপসংহার
