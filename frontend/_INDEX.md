# frontend/ — File Index
> AI: পুরো ফোল্ডার স্ক্যান না করে এই index পড়ুন। এটি SupremeAI-এর Studio (React/Vite) অ্যাপ্লিকেশন।

## Key Directories
| Directory | কী আছে |
|---|---|
| `src/` | Main application code (React components, pages, hooks, services) |
| `public/` | Static assets (images, icons) |
| `e2e/` | Playwright end-to-end tests |
| `scripts/` | Frontend specific build/automation scripts |
| `dist/` | Production build output |

## Important Configuration Files
| File | কী করে |
|---|---|
| `vite.config.ts` | Vite bundler configuration |
| `tailwind.config.js` | Tailwind CSS configuration |
| `eslint.config.js` | ESLint rules |
| `tsconfig.json` | TypeScript configuration |
| `package.json` | Dependencies and npm scripts (`dev`, `build`, `test`) |

## Running Locally
```bash
cd frontend
pnpm install
pnpm run dev
```
