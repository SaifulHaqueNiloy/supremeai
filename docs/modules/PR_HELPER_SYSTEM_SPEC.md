# 4-Agent PR Helper Spec
1. Goal: ব্লাইন্ড CI (২৬ জব) নির্ভরতা বাদ দিয়ে স্বয়ংক্রিয়ভাবে Improvement বনাম Regression নির্ধারণ।
2. Agent 1 (Intent): ডিফের আসল উদ্দেশ্য ও কোড পরিবর্তন সেমান্টিকালি যাচাই করে।
3. Agent 2 (Security): URL মিউটেশন ও সিক্রেট লিক শনাক্ত করে; কোনো ঝুঁকি থাকলে সাথে সাথে VETO (ব্লক)।
4. Agent 3 (Autopsy): CI ফেইলরটি পিআরের কারণে নাকি পুরোনো ফ্ল্যাক/রেট-লিমিটের কারণে তা চিহ্নিত করে।
5. Agent 4 (Arbiter): পূর্ববর্তী ৩ এজেন্টের রিপোর্টের ভিত্তিতে চূড়ান্ত রায় দেয়।
6. Rule: Security ক্লিয়ার + Valid Intent হলে ২৬টি জব ফেইল থাকলেও CI ওভাররাইড করে মার্জ।
7. Rule: ২৬টি জব পাস হলেও অননুমোদিত URL চেঞ্জ থাকলে সরাসরি রিজেক্ট।
8. Rule: কোনো বাহ্যিক GitHub Settings নয়; পুরো সিদ্ধান্ত সুপ্রিমএআই কন্ট্রোল টাওয়ারে গৃহীত হবে।
